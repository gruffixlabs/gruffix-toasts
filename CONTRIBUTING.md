# Contributing

Thanks for your interest in GruffixToasts. Bug reports, fixes and improvements are welcome.

## License

GruffixToasts is released under the [MIT License](LICENSE). By submitting a contribution, you agree that it's
licensed under the same MIT License (inbound = outbound), and that you have the right to submit it.

## Upstream your fixes

If you fork GruffixToasts or patch it in your own app, please send the fix back as a pull request so everyone
benefits. Small, focused pull requests are easiest to review. For larger changes, open an issue first to talk through
the approach.

## Setup, building and testing

The [Contributing article](https://gruffixlabs.github.io/gruffix-toasts/documentation/gruffixtoasts/contributing)
in the documentation covers the repository layout, building and testing on every platform, and the demo app. Its
source is `Sources/GruffixToasts/GruffixToasts.docc/Contributing.md`.
